# 💫 ¡Hola! Soy Ángel Sánchez 👋

### 👨‍💻 Software Engineer | Full-Stack
Transformando 20 años de liderazgo técnico en **Automatización Industrial (PLC y HMI)** en soluciones digitales modernas. Actualmente, aportando valor en **Electric Automation Network (EAN)** mediante el desarrollo de software que une la precisión industrial con la agilidad del ecosistema web Full-Stack.

Mi objetivo es optimizar procesos complejos mediante código limpio, arquitecturas escalables y una visión 360° del ciclo de vida del dato.

---

### 🚀 ¿En qué estoy trabajando actualmente?

- **High-Performance Web:** Desarrollando una **Landing Page con Astro y JS** optimizada para alcanzar un **100% en Core Web Vitals (Performance)**, aplicando técnicas de *static site generation* y carga eficiente de recursos.
- ⚡ **Backend Architect:** Diseñando arquitecturas escalables con **FastAPI (Python)** para la implementación de microservicios, integración avanzada con **React** y gestión dinámica de múltiples bases de datos (SQL/NoSQL) con validación mediante **Pydantic**.
- 🐍 **Data Automation:** Escalando motores de **Web Scraping** de alto rendimiento para auditorías masivas, logrando una reducción del **95% en tiempos de proceso** mediante Playwright y procesos asíncronos.
- 🏗️ **Cloud & DevOps:** Desplegando infraestructuras escalables en **AWS** (VPC, EC2, CloudWatch) y optimizando el ciclo de vida del software mediante contenedores **Docker**.
- 🌐 **Comunidad IT/OT:** Dirigiendo [tecnoplc.com](https://www.tecnoplc.com), el portal de referencia donde comparto conocimiento sobre programación de sistemas Siemens e integración de nuevas tecnologías en la industria.
- ⚽ **Gestión Deportiva (Full-Stack):** Plataforma integral para la dirección técnica de equipos de fútbol.
  - **Arquitectura:** Frontend reactivo con **Vue.js** y **JavaScript (ES6+)**, maquetado con **CSS3 puro** (sin frameworks) para un control total del diseño y rendimiento.
  - **Backend & Seguridad:** API robusta desarrollada en **PHP**, implementando un sistema de autenticación segura mediante **JWT (JSON Web Tokens)** y encriptación de datos.
  - **Data Management:** Diseño de una arquitectura de datos compleja en **MySQL** para gestionar entrenamientos, tácticas y estadísticas de jugadores en tiempo real.
